Git — это программа, которую разработчик устанавливает на свой компьютер.
GitHub — это онлайн-сервис (платформа), который строится на базе Git
Использованные команды: git status показывает общее состояние файлов, git diff — незастейдженные изменения, а git diff --staged — изменения, уже добавленные в индекс и готовые к коммиту.
Ветка — именованный указатель на коммит, позволяющий вести параллельную работу.



При новом коммите ветка автоматически сдвигается вперёд, на новый коммит.



Слияние — объединение изменений одной ветки в другую; при конфликте одинаковых строк его разрешают вручную.
